# Visual assets

I use `lailow-cover-v5.png` as generated brand artwork. It is an abstract visual identity, not an application screenshot or a measured result.

`dashboard-overview.jpg` and `dashboard-landscape.jpg` are unaltered screenshots of my Streamlit interface running its deterministic synthetic dataset: 168 fictional daily records, six campaigns, and product identifiers prefixed with `SYN-`. They contain no private business records.

The `signal-study` animation and static plot are generated from the separate 42-record public analytics fixture. I include its renderer and plotted totals so the visual can be reproduced.
